# 2.3 - The Gear Menu

**Let's get your AI ready to write!**

Click the **gear icon** in the upper-right corner to open Settings. There are several options here, but we'll focus on getting an AI model ready for your first generation.

## Choose How You'll Use AI

SJB Writer supports two ways to work with AI:

- **Online models through OpenRouter:** Access a wide selection of AI models using an API key. Some models are free, while others charge based on usage.
- **Local models through Ollama:** Run AI models directly on your computer, without sending your writing to an online model service. You'll need to install Ollama and download a model first.

You can use either method, or both.

## Using OpenRouter

If you'd like to use online models:

1. Visit **[OpenRouter.ai](https://openrouter.ai)** and create an account.
2. Create an API key. Add credits if needed for the models you want to use.
3. Back in SJB Writer, find **API Key** in Settings, paste your key, and click **Save**.

I recommend avoiding automatic credit refills, at least while you're getting started. It gives you more control over spending.

## Select Your Model

Open **Models Manager** in Settings.

If you already have Ollama models installed, they should appear automatically.

To add an OpenRouter model:

1. Find a model on OpenRouter and copy its **Model ID**.
2. Click **+ Add Model** in SJB Writer and paste that ID.
3. Click **Verify** to retrieve its details.
4. Adjust its display name if you'd like, then click **Create Model**.

Select the model you want to use from the model dropdown.

You're ready to generate!

## A Couple of Other Settings

- **Books Folder:** Lets you choose where SJB Writer stores your projects and files. You don't need to change it to get started.
- **Visual settings:** Let you customize the workspace to suit your preferences.

You can explore these later. For now, let's put that AI model to work!
